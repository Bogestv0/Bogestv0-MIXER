# Политика подписи кода

Этот документ нужен для заявки в SignPath Foundation (бесплатная подпись для открытых проектов) и описывает, что и как подписывается.

## Что подписывается
- Установщик Windows `Bogestv0 MIXER_<версия>_x64-setup.exe` и исполняемые файлы внутри него (`Bogestv0 MIXER.exe`, `engine.exe`).
- Только файлы, собранные из этого публичного репозитория в GitHub Actions (`.github/workflows/release.yml`) по тегу вида `vX.Y.Z`. Локальные сборки не подписываются.

## Что не подписывается этим сертификатом
- Драйвер виртуальных устройств (`driver/`). Он работает в тестовом режиме Windows; подпись драйвера через Microsoft Partner Center требует отдельного платного сертификата и сейчас не делается.

## Кто и как утверждает подпись
- Автор и владелец репозитория (`Bogestv0`) единственный, кто создаёт теги релизов и утверждает подпись.
- Исходный код открыт (лицензия MIT), история изменений публичная (`CHANGELOG.md`).
- Программа не содержит вредоносного кода и не обходит защиту системы. Драйвер создаёт только виртуальные звуковые устройства.

## Конфиденциальность
Программа сама ничего не отправляет в сеть, кроме проверки обновлений на GitHub Releases и (по запросу пользователя) подключения к OBS на этом же компьютере.
