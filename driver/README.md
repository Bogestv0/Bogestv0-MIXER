# Драйвер Bogestv0 Virtual Audio

Виртуальные аудиоустройства **Bogestv0 Input 1–6** (воспроизведение) и **Bogestv0 Output 1–2** (запись). Основа: пример Microsoft SysVAD
(лицензия MS-PL, см. `UPSTREAM.md`). Код Microsoft в репозитории не хранится: сборка (`.github/workflows/driver.yml`) скачивает закреплённую
версию, накладывает `patch_sysvad.py` и собирает.

## Как драйвер попадает к пользователю
Вручную ничего ставить не нужно. Сборка релиза (`.github/workflows/release.yml`) вызывает `driver.yml`, кладёт результат в `src-tauri/driver/`
и Tauri упаковывает его в установщик. Установщик (`src-tauri/windows/hooks.nsh`) после копирования файлов запускает
`install.ps1 -Auto`, а при удалении программы `uninstall.ps1 -Auto`. Автообновление микшера делает то же самое: новая версия драйвера
приходит вместе с установщиком. Если файлы драйвера не изменились (сравнение SHA-256 с последней удачной установкой), драйвер не трогается.

## Файлы
| Файл | Для чего |
|---|---|
| `install.ps1` | Установка: тестовый режим → сертификат → пакет (`pnputil`) → устройство (SetupAPI). Без ключей работает как раньше (вручную, от администратора). `-Auto`: режим установщика (без вопросов, включает тестовый режим сам, коды выхода, журнал). |
| `uninstall.ps1` | Удаление устройства и пакетов драйвера (поставщик Bogestv0). `-Auto`: режим деинсталлятора; при обновлении микшера (`/UPDATE`) ничего не делает. |
| `install-driver.cmd`, `uninstall-driver.cmd` | Запасной ручной запуск двойным щелчком: сами запрашивают права администратора. Лежат в папке `driver` в каталоге программы. |
| `patch_sysvad.py`, `src/` | Правки к SysVAD и наш код моста с движком. |

## Тестовый режим и Secure Boot
Драйвер подписан тестовым сертификатом WDK, поэтому Windows принимает его только в тестовом режиме (`bcdedit /set testsigning on`). Установщик
включает его сам и просит перезагрузку; после перезагрузки драйвер доустанавливает задача Windows `Bogestv0DriverSetup` (от имени системы,
после успеха удаляет сама себя). Secure Boot должен быть выключен, иначе Windows не включит тестовый режим (код выхода 20).
Окончательное решение: подпись драйвера через Microsoft Partner Center (этап 8.3).

## Коды выхода `install.ps1 -Auto`
`0` готово · `3010` нужна перезагрузка · `20` тестовый режим не включился (Secure Boot) · `21` после перезагрузки он всё ещё выключен · `1` прочая ошибка.
Журнал: `%ProgramData%\Bogestv0\driver-setup.log`.

## Ручная проверка скриптов (разработчику)
PowerShell от администратора, из папки с файлами драйвера: `powershell -ExecutionPolicy Bypass -File install.ps1 -Auto`; повторный запуск должен
ответить «Драйвер этой версии уже установлен и работает» и выйти. Удаление: `uninstall.ps1`.
