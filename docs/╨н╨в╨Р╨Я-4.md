# Этап 4: микрофоны

## Что работает
- **Цепочка обработки микрофона** (для HW1 и HW2, в движке): фильтр низких частот → усиление → шумоподавление → гейт → компрессор → мягкий ограничитель. Дальше обычный путь: фейдер, Mute/Solo, маршруты.
- **Шумоподавление** на нейросети RNNoise (Мозилла/Xiph, лицензия BSD-3, лежит в `engine/third_party/rnnoise`, ничего не скачивается при сборке).
  - «Мягкое» — гул вентилятора, шум комнаты. «Сильное» — ещё клавиатура и мышь (паузы без голоса дополнительно приглушаются на 6 дБ). «Максимум» — остаётся только голос (паузы приглушаются на 20 дБ).
  - Ползунок «Сила подавления» (0–100 %) — доля обработанного звука в смеси. Режимы ставят свою силу по умолчанию: 50 / 70 / 100 %.
  - Задержка микрофона +10 мс, пока шумодав включён. Выключили — задержки нет. Включение и выключение идёт плавно, без щелчков.
- **Усиление** 0…+30 дБ программное; всё, что выше −1 дБ полной шкалы, мягко прижимается (перегрузка не трещит).
- **Гейт** −80…−20 дБ (−80 = выключен): быстро открывается, держится 120 мс после слова, закрывается плавно.
- **Фильтр низких** 20…300 Гц (20 = выключен), 24 дБ на октаву.
- **Компрессор** 1…10 : 1 (1 = выключен), порог −20 дБ, автоматически возвращается половина «потерянной» громкости.
- **Экран «Микрофон»** (`Микшер` → нажмите на слово с режимом шума в карточке микрофона, например «Сильное ›»): все ползунки сразу меняют звук. Внизу «Проверка» показывает реальный уровень фона в паузах до и после подавления (самый тихий участок за последние ~3 секунды).
- **На «Микшере»:** кнопки Выкл / Мяг / Сил / Макс переключают шумодав, крутилки «Гейт» и «Компр.» крутятся перетаскиванием вверх-вниз (двойной щелчок возвращает значение по умолчанию). На подпись крутилки при перетаскивании выводится значение.
- Настройки микрофонов лежат в `bogestv0-settings.json` (поле `mics`) и возвращаются при запуске. Настройки из версии 0.1.0 (режим шума) переносятся сами.

## Значения по умолчанию (как в макете)
| | Микрофон 1 | Микрофон 2 |
|---|---|---|
| Усиление | +10 дБ | +10 дБ |
| Гейт | −45 дБ | −45 дБ |
| Фильтр низких | 80 Гц | 80 Гц |
| Компрессор | 3 : 1 | 3 : 1 |
| Шумодав | Сильное, 70 % | Мягкое, 50 % |

Если для вашего микрофона +10 дБ слишком много или мало, нажмите нужную кнопку +0 / +10 / +20 / +30 на экране «Микрофон».

## Как проверить руками (после установки версии 0.2.0)
1. Закройте Voicemeeter. На экране «Устройства» микрофон на HW1, наушники на A2 (как в этапе 3). **Только в наушниках!**
2. «Микшер»: у «Микрофон 1» включите **A2**. Вы слышите себя.
3. Включите вентилятор, пощёлкайте клавиатурой. Нажмите «Выкл», затем «Мяг», «Сил», «Макс»: фон должен становиться заметно тише, а голос оставаться понятным. В режиме «Макс» между фразами должна быть почти тишина.
4. Откройте экран «Микрофон» (нажмите «Макс ›» над кнопками). Помолчите 3 секунды: внизу «Без обработки» и «С подавлением» покажут уровни; разница обычно 15–30 дБ.
5. Подвигайте «Порог гейта»: чем выше порог, тем раньше микрофон «закрывается» между словами. Если обрезает начало слов, опустите порог.
6. «Фильтр низких частот»: постучите по столу. Чем выше частота, тем меньше стука.
7. «Компрессор»: говорите то тихо, то громко — разница в громкости должна уменьшаться. «Усиление» выше +20 дБ даёт шум; для тихих микрофонов лучше использовать шумодав вместе с усилением.
8. Закройте программу совсем (трей → Выход), откройте снова: ползунки и режимы на местах.
9. Нагрузка: откройте «Диспетчер задач» и проверьте процесс `engine.exe` при двух включённых шумодавах. Он должен занимать несколько процентов одного ядра. В игре следите, нет ли щелчков.
