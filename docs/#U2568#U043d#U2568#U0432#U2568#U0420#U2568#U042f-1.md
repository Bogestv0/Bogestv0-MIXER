# Этап 1: что сделано и как запустить

## Что внутри
- `app/` — экраны в обычном HTML/JS (Микшер, Микрофон, Сцены, Эффекты, Запись, Дорожки и аудио, а также старые Выходы, Устройства, Настройки). Шрифты лежат внутри, интернет для запуска не нужен.
- `src-tauri/` — оболочка Tauri: окно, значок в трее, проверка обновлений.
- `.github/workflows/release.yml` — по тегу `vX.Y.Z` собирает установщик и публикует Release.
- `ui/` — исходные макеты, оставлены как образец. `tools/port-screens.mjs` — разовый конвертер `.dc.html` в `app/`. Дальше правим файлы в `app/` напрямую (повторный запуск конвертера затрёт блок «Обновления»).

Блок «Обновления» добавлен в Настройки (версия, «Проверить сейчас», автопроверка, «Что нового»).

## Что нужно сделать вам (один раз)
1. Создайте публичный репозиторий `Bogestv0-MIXER` и загрузите в него всё содержимое этой папки.
2. Замените `OWNER` на ваш логин GitHub в двух местах: `src-tauri/tauri.conf.json` (адрес `endpoints`) и `app/app.js` (строка `REPO`).
3. Создайте ключ подписи обновлений на своём компьютере: `npm install`, затем `npx tauri signer generate -w %USERPROFILE%\.tauri\bogestv0.key`. Задайте пароль и запомните его.
4. Содержимое файла `bogestv0.key.pub` вставьте в `src-tauri/tauri.conf.json`, поле `pubkey`.
5. В репозитории: Settings → Secrets and variables → Actions → New repository secret. Добавьте `TAURI_SIGNING_PRIVATE_KEY` (содержимое файла `bogestv0.key`) и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (пароль). Файл `.key` никому не показывайте и в репозиторий не кладите.
6. Settings → Actions → General → Workflow permissions → Read and write permissions.

## Выпуск версии
1. Поднимите версию в трёх файлах одинаково: `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.
2. Допишите раздел `## [X.Y.Z]` в `CHANGELOG.md`: он станет текстом «Что нового».
3. Создайте тег `vX.Y.Z` (например `v0.0.1`). Через 10–15 минут в Releases появится установщик.

## Проверка этапа 1
Установите 0.0.1, выложите 0.0.2 (шаги выше). При следующем запуске микшер предложит обновиться; кнопка «Проверить сейчас» в Настройках делает то же самое.
